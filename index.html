Mã quy tắc: C — quy định chung, E — cấu trúc câu hỏi, T — TikZ, B — bảng biến thiên, #n — mục n của Bảng kí hiệu. Máy sửa theo luật nên vẫn cần biên dịch lại và đọc soát trước khi nộp.

PDF → LaTeX

Chọn file PDF đề, web dựng lại code LaTeX theo mẫu ex_test (công thức, câu trắc nghiệm, đúng sai, trả lời ngắn, lời giải) và chuẩn hoá theo bộ luật. Hình vẽ được cắt thành ảnh, tải kèm file .zip.

PDF → Word

Chọn file PDF đề, web chuyển thẳng sang file Word (.docx): công thức là Equation của Word (bấm vào sửa được; MathType: tab MathType → Convert Equations để đổi toàn bộ sang MathType), hình vẽ được cắt từ PDF và chèn đúng vị trí, đúng mẫu câu trắc nghiệm, đúng sai, trả lời ngắn.
