Mã quy tắc: C — quy định chung, E — cấu trúc câu hỏi, T — TikZ, B — bảng biến thiên, #n — mục n của Bảng kí hiệu. Máy sửa theo luật nên vẫn cần biên dịch lại và đọc soát trước khi nộp.

Chuyển đổi đề LaTeX → Word có Equation · PDF → LaTeX / Word — chạy ngay trên trình duyệt, không cần key AI

1

Hình vẽ TikZ (bỏ qua nếu đề không có hình)

Trình duyệt không chạy được LaTeX, nên hình được lấy từ chính bản biên dịch của bạn: tải file hình về, biên dịch bằng pdfLaTeX như đề bình thường (mỗi hình một trang), rồi chọn file PDF đó.

2

Xuất file Word

Lấy code ở khung Code đã chuẩn hoá (nếu trống thì lấy code gốc). Công thức là Equation thật của Word — bấm vào sửa được, MathType chuyển đổi được.

1

Chọn file PDF đề

PDF xuất từ LaTeX hoặc Word (bôi đen chọn được chữ) cho kết quả tốt nhất: web đọc chữ, font và nét vẽ để dựng lại công thức, nhận dạng Câu / A. B. C. D. / a) b) c) d) / Lời giải, cắt hình thành ảnh. PDF scan (ảnh chụp) chỉ nhận dạng được chữ, công thức phải gõ lại.

2

Kết quả
