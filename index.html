        Thêm hình vào kho (quản trị viên)

        Nạp nhiều file .tex (chọn hoặc kéo thả cả chục, cả trăm file một lúc): web tự tách mọi hình TikZ trong từng file kèm câu hỏi chứa nó, vẽ thử, bỏ hình trùng rồi lưu thẳng vào kho. Hoặc dán code vào ô dưới. Hình dùng lệnh riêng (\IntervalLR, \tikzset…) định nghĩa trong file .sty của bạn: chọn kèm file .sty đó, hoặc dán định nghĩa vào mục “Lệnh dùng chung”.

        Lệnh dùng chung

        Dán định nghĩa các lệnh riêng mà hình của bạn dùng (\newcommand, \def, \tikzset, \colorlet… — thường nằm trong file .sty hoặc phần đầu đề). Web nạp kèm khi vẽ hình trong kho. Mọi tài khoản dùng chung, chỉ quản trị viên sửa được.

        Bộ vẽ hỗ trợ TikZ, pgfplots, tkz-tab, tkz-euclide, tikz-3dplot, circuitikz, tikz-cd, venndiagram và biểu tượng \faUser, \faIcon{…} (Font Awesome Free, giấy phép CC BY 4.0).
