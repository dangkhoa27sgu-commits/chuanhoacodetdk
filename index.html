        Thêm hình vào kho (quản trị viên)

        Nạp nhiều file .tex (chọn hoặc kéo thả cả chục, cả trăm file một lúc): web tự tách mọi hình TikZ trong từng file kèm câu hỏi chứa nó, vẽ thử, bỏ hình trùng rồi lưu thẳng vào kho. Hoặc dán code vào ô dưới. Hình dùng lệnh riêng (\IntervalLR, \tikzset…) định nghĩa trong file .sty của bạn: chọn kèm file .sty đó, hoặc dán định nghĩa vào mục “Lệnh dùng chung”.

        Lệnh dùng chung

        Dán định nghĩa các lệnh riêng mà hình của bạn dùng (\newcommand, \def, \tikzset, \colorlet… — thường nằm trong file .sty hoặc phần đầu đề). Web nạp kèm khi vẽ hình trong kho. Mọi tài khoản dùng chung, chỉ quản trị viên sửa được.

        Hình thực tế trong đề

        Các hình dưới đây là ảnh chụp / tranh thực tế. Với mỗi hình chọn: Vẽ mô phỏng (AI) — AI đọc đề bài và dựa vào thư viện hình mẫu để vẽ sơ đồ TikZ rõ nét (hợp với ảnh mờ, phức tạp); Dò theo ảnh — vẽ lại theo đường nét của ảnh; hoặc Lược bỏ (bỏ đi không ảnh hưởng bài toán). Gợi ý đã được đánh dấu sẵn.

        Cấu hình AI đọc PDF scan

        Chỉ dùng cho trang scan, ảnh chụp. PDF xuất từ Word, LaTeX luôn đọc trực tiếp, không cần AI.

        2. Đăng nhập bằng Gmail

          Bấm nút + Create API key ở góc trên bên phải. Nếu Google hỏi chọn dự án (project), chọn dự án có sẵn hoặc tạo dự án mới với tên bất kì.

          Khoá hiện ra có dạng AIzaSy…⧉ — bấm biểu tượng sao chép bên cạnh.

        5. Dán vào đây rồi kiểm tra

          Bấm vào ô Khoá API bên dưới, dán (Ctrl+V; điện thoại: giữ ngón tay → Dán), bấm Kiểm tra khoá. Thấy dòng ✓ màu xanh là xong, bấm Lưu cấu hình.
