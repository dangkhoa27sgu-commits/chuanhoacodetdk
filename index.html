      2. Đăng nhập bằng Gmail

      3. Tạo khoá

        Bấm nút + Create API key ở góc trên bên phải. Nếu Google hỏi chọn dự án (project), chọn dự án có sẵn hoặc tạo dự án mới với tên bất kì.

      4. Sao chép khoá

        Khoá hiện ra có dạng AIzaSy…⧉ — bấm biểu tượng sao chép bên cạnh.

      5. Dán vào đây rồi kiểm tra

        Bấm vào ô Khoá API bên dưới, dán (Ctrl+V; điện thoại: giữ ngón tay → Dán), bấm Kiểm tra khoá. Thấy dòng ✓ màu xanh là xong, bấm Lưu cấu hình.
